# 권지혁으로 살아가기

대한민국에서 태어나 선택에 따라 다른 인생을 경험하는 허구의 블랙코미디 웹게임.

## 실행

`index.html`을 열거나 정적 웹 서버에서 실행합니다. 별도 설치·빌드·로그인은 필요 없습니다.

## GitHub Pages 배포

1. 새 GitHub 저장소를 만듭니다.
2. 이 폴더 안의 파일(`index.html`, `styles.css`, `game.js`, `routes.js`, `assets/`)을 저장소 최상위 경로에 올립니다.
3. **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main` / `/(root)`를 선택합니다.
4. GitHub Pages에서 표시한 사이트 주소를 엽니다.

## 게임 구성

- 전개 선택 9단계. 지정된 모든 선택이 이어지면 평범한 직장인 결말 1개가 숨겨져 있습니다. 게임 화면에는 진행 조건이나 확률을 미리 노출하지 않습니다.
- 그 외 세계선 3가지 큰 방향 → 9가지 하위 분야 → 27가지 서로 다른 직함.
- 각 직함별 **24가지 결말**로 분기하며, **서로 다른 부정적 엔딩 648개**가 실제로 도달 가능합니다.
- 마지막 6단계의 선택 조합(3⁶=729)이 24개 결말을 결정합니다. 어떤 결말도 미사용 더미 데이터가 아닙니다.
- 엔딩 도감에서 발견한 결말을 수집합니다. 발견 기록은 각 브라우저 `localStorage`에 저장됩니다.
- 결과 화면에는 엔딩 이름과 캐릭터만 표시하며, 평가성 문구 및 추가 설명은 보이지 않습니다.
- 비례를 다시 조정한 캐릭터(원본 얼굴 사진 픽셀 유지). 엔딩 PNG 카드 저장, 결과 복사, 자동 진행, 모바일 레이아웃 포함.
- `routes.js`에는 27개 캐릭터 유형과 24개 결말 패턴, 자동 생성된 고유 엔딩 ID `B01-01`부터 `B27-24`까지가 수록되어 있습니다.
- `endings_648.csv`에는 각 엔딩의 **고유 번호·주제·제목·이야기**가 648행으로 정리돼 있습니다.

## 파일

- `index.html`: 시작 페이지
- `styles.css`: UI 디자인
- `routes.js`: 648개 분기의 원본 데이터
- `game.js`: 선택, 엔딩 계산, 기록, 도감, 이미지 저장
- `assets/jihyeok-cool.png`, `assets/jihyeok-smile.png`: 제공된 사진에서 **픽셀을 재생성하지 않고 오려낸 얼굴**
- `assets/character-*.png`: 새 전신 비율로 제작한 의상과 실제 얼굴 합성 이미지
- `endings_648.csv`: 엔딩 목록(참고·검증용)

**주의:** 사진 속 실존 인물이 실제로 범죄를 저질렀다는 뜻이 전혀 없는 허구의 패러디입니다. 사이트를 공개 배포하기 전에 당사자의 얼굴·이름 사용에 대한 동의를 받으세요.
